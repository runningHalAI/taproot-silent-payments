# Taproot Silent Payments (prototype)

Educational prototype demonstrating a simple method to create "silent payments" using Taproot (BIP341/BIP341-style tweaks).

What this repo contains

- silent_taproot.py — Python library that:
  - Derives a one-time Taproot output public key from a recipient's long-term Taproot internal key and a sender ephemeral key using ECDH.
  - Produces the x-only public key and a Bech32m P2TR address (mainnet or testnet HRP).

Why this matters

Silent payments let a sender create a single-use output that the recipient can detect and spend without broadcasting a public key beforehand. It's useful for improving payer privacy and reducing address reuse. This is a prototype for exploration and teaching — not production-ready.

Quick start

1) Install dependencies:

```bash
pip install coincurve
```

2) Example (Python):

